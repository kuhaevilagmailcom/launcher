# АНОН МГН

Telegram-чат для Магнитогорска на Python, aiogram 3 и SQLite. Пол, возраст и берег необязательны; пол и берег используются только как приоритеты поиска.

## Возможности

- поиск случайного собеседника; пол и берег работают как мягкие приоритеты, а недавно завершённая пара временно не выдаётся повторно;
- очередь поиска бессрочная; совместимые пары пересобираются автоматически, в том числе после рестарта;
- публичный анонимный ник и очки; Telegram username и ID скрыты от обычных пользователей;
- модерация может использовать Telegram-данные при жалобах и нарушениях;
- жалобы с последними сообщениями и модерацией;
- пересылка обычных сообщений, включая `@username`, ссылки `t.me/...`, телефоны и Telegram-контакты; нативные Telegram reply сохраняют привязку к конкретному сообщению, пока жив текущий процесс;
- фиксированный набор custom emoji и кеширование Telegram `file_id` экранов;
- реферальный экран `/ref` с кнопками копирования/отправки ссылки, начислением 50 очков и лимитом 30 наград в сутки;
- одноразовая награда 100 ⭐ за подписку на @anonmgn с проверкой через Telegram; повторная подписка награду не выдаёт;
- игры в активном диалоге: «Битва мнений» на 5/10 вопросов и «Числа» на 3 раунда с диапазонами 1–10, 1–100 и 1–1000; награда в «Числах» доступна только в первой игре конкретной пары и ограничена 300 ⭐ в сутки на пользователя; игры без активности автоматически удаляются через 48 часов;
- итог диалога показывает длительность, количество сообщений и статистику реально сыгранных игр без раскрытия личности собеседника;
- серия активности по нормальным диалогам, скрытые одноразовые достижения и ежедневные квесты с наградами;
- личная активность за сегодня / 7 / 30 дней; дневные агрегаты старше 40 дней автоматически очищаются;
- топы за неделю, 30 дней и всё время переключаются в одном экране;
- «Онлайн сейчас» показывает всех пользователей, взаимодействовавших с ботом за последние 5 минут, отдельно очередь, общающихся, свободных и дневной пик;
- обратная связь из настроек: текст и медиа уходят всем админам;
- добровольная поддержка Stars: любая сумма от 1 ⭐ навсегда добавляет к нику 💎;
- администраторы с отдельными правами на жалобы, пользователей, мут, бан, рассылку и очки; отдельный экран диагностики показывает аптайм, БД, очередь, игры, ошибки доставки, janitor и reply-map;
- удаление профиля без снятия действующего бана или мута.

## Команды

`/start` — меню · `/connect` — поиск · `/next` — следующий · `/stop` — выйти · `/game` — игры в диалоге · `/report` — жалоба · `/profile` — профиль и реферальная ссылка · `/settings` — настройки · `/ref` — реферальная ссылка · `/support` — поддержать проект · `/help` — помощь · `/forget` — удалить профиль.

Владельцы задаются через `ADMIN_IDS`. Они имеют все права и назначают остальных:

```text
/adminadd 123456 reports,users,mute
/adminperms 123456 all
/admindel 123456
/adminlist
/points 123456 +50
/points 123456 -50
/purge_referrals 123456
```

`/purge_referrals` доступна только владельцу: показывает предпросмотр, а после
подтверждения снимает только реферальные награды и удаляет прямых фейк-рефералов. Аккаунты
с платежами или правами администратора, платежи и оплаченные Telegram Stars сохраняются.

Доступные права: `stats`, `reports`, `queue`, `users`, `broadcast`, `mute`, `ban`, `points`, `monitor`. Право `all` также включает наблюдение за чатами. Интерфейс скрывает недоступные разделы, а каждый обработчик повторно проверяет право на сервере.

Владелец из `ADMIN_IDS` и администраторы с правом `monitor` могут включить получение копий сообщений активных диалогов кнопкой «Чаты». Копии отправляются отдельно от основного пути доставки, чтобы мониторинг не тормозил собеседников. В копии видны username, анонимный ник и ID обоих собеседников. Владелец также может скачать согласованную резервную копию работающей SQLite кнопкой «Скачать базу».

## Запуск

```bash
git clone https://github.com/kuhaevilagmailcom/launcher.git
cd launcher
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python main.py
```

## Mini App на Bothost

Бот запускает polling и HTTP API Mini App в одном процессе. Благодаря этому
поиск, текущие пары, игры и SQLite у бота и приложения всегда общие.

В панели Bothost:

1. Укажи `main.py` как главный файл и подключи постоянное хранилище к `/app/data`.
2. Включи домен и порт. Код слушает `0.0.0.0` и автоматически использует
   переменную `PORT`, которую передаёт Bothost.
3. Если приложение должно открываться с домена этого же BotHost, задай
   `MINIAPP_URL=https://твой-домен.bothost.tech`. Бот сам установит кнопку меню.
4. Если frontend уже размещён отдельно, задай его origin в
   `MINIAPP_ALLOWED_ORIGINS` и укажи публичный URL BotHost в `api-base` его
   `index.html`. Origin — это только схема и домен, без пути.

Проверка после запуска: `https://твой-домен/api/miniapp/health` должна вернуть
`{"ok": true, "service": "anon-mgn-miniapp"}`. Токен и `.env` в Git не добавляй.

Основные переменные `.env`:

```dotenv
BOT_TOKEN=
ADMIN_IDS=
DATABASE_PATH=data/anonchat_mgn.db

CITY_NAME=Магнитогорск
CITY_SHORT=МГН

SUBSCRIPTION_CHANNEL=@anonmgn
SUBSCRIPTION_CHANNEL_URL=https://t.me/anonmgn
SUBSCRIPTION_REWARD=100

AUTO_MUTE_REPORTS=3
AUTO_MUTE_MINUTES=60
REPORT_CONTEXT_RETENTION_DAYS=7

DROP_PENDING_UPDATES=false
MESSAGE_RATE_LIMIT=120
MENU_RATE_LIMIT=60
RECENT_PARTNER_COOLDOWN_MINUTES=30

```

`AUTO_MUTE_REPORTS=0` выключает авто-мут. Путь `DATABASE_PATH` обязан быть доступен для записи: при ошибке бот завершает запуск и не переходит на временную базу.

## База данных

SQLite обновляется при старте без удаления существующих данных. Основные таблицы: `users`, `admins`, `matches`, `battle_games`, `number_game_pairs`, `number_daily_rewards`, `daily_activity`, `user_engagement`, `reports`, `referrals`, `payments`, `kv`. Reply message_id и последние тексты активного диалога хранятся только в памяти процесса и в SQLite не записываются. Состояние матчмейкера сохраняется с debounce, а не после каждого сообщения. `telegram_payment_charge_id` уникален, поэтому один платёж не обрабатывается повторно. Контекст закрытых жалоб очищается после срока `REPORT_CONTEXT_RETENTION_DAYS`.

## Telegram Stars

`/support` создаёт счёт на выбранное пользователем количество Stars. После первого подтверждённого платежа к публичному нику добавляется 💎; сумма поддержки хранится в профиле и защищена от повторной обработки одного charge ID.
